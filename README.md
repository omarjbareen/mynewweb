# WoodVision Assistant

A smart guided wood and furniture material selection platform for customers designing homes, kitchens, bedrooms, offices, closets, and caravans.

## Getting Started

1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`
3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Folder Structure

- `src/components/`: Reusable React components (Navbar, HeroSection, etc.)
- `src/pages/`: Page components (HomePage, WizardPage, ResultsPage)
- `src/data/`: Mock data for wood products
- `src/styles/`: CSS stylesheets
- `src/assets/`: Images and other assets

## Features

- Responsive landing page with navigation
- Material selection wizard
- Results display
- Modern CSS styling with warm wood-inspired colors

## Technologies

- React
- Vite
- React Router
- JavaScript (ES6+)
